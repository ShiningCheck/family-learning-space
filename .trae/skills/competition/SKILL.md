# 比赛

把**学校发来的比赛/活动通知**（自愿报名的美育节、艺术节、各类展示活动）整理成一页，给孩子和家长一起用：
读完要求就知道该准备什么，选好参加的项目，照着备赛清单一项一项打卡，翻日历还能回看和补记。

## 这个技能做什么

1. **读懂通知**：把通知里的项目（表演类的器乐/声乐/舞蹈、作品类的绘画/书法篆刻……）、
   展示要求、录制要求、上交要求、负责老师与邮箱、截止时间，整理成 `data/notice.json`。
2. **选项目**：页面上按类选「我们参加哪一项」（每类最多一项，也可以「先不参加」），选择结果落服务器、跨设备同步。
3. **备赛清单打卡**：每个项目一组步骤（定曲目 → 背谱练熟 → 布置场地 → 一镜到底录视频 → 发给老师……），
   点一下就是打卡；打卡粒度到**每一步**，不是笼统的「已完成」。
4. **日历回看与补打卡**：整页一个打卡日历（绿点＝那天完成了几项），点某天就能看到那天完成的步骤、
   以及那天录的音；切到过去某天再点步骤，就是「补记那天完成的」。
5. **练习心得**：录一段话（音频 + 识别文字双显示），留档在 `data/voice/`（门户统一管理）。
6. **倒计时**：顶部常驻「距离上交还有 N 天」，看到就不会忘。

## 触发场景

- 用户发来学校比赛/活动通知（PDF、图片、截图），说「把这个要求加到比赛页」「孩子报个名」「准备一下」；
- 用户问「比赛要准备什么」「什么时候交」「发给哪个老师」；
- 用户说「我们报了器乐」「帮我打卡备赛」「练完了」。

## 目录约定（不要改）

**代码侧**（本技能目录，公开、可分发）：

```
competition/
├── SKILL.md            # 本文件
├── skill.json          # 声明 url 前缀 / 代码目录 / 数据目录（服务器与 tools/data_paths.py 据此解析）
├── DATA.md             # 数据落在哪里（仓库之外的 data-root）
├── data-templates/     # 匿名模板：data-root 里的 data/ 由它生成，**这里永远不放真实信息**
│   ├── config.json     # 孩子称呼 / 年级 / 班级
│   ├── notice.json     # 活动通知结构（学校名、老师、邮箱都写成占位符）
│   └── state.json      # 报名 + 打卡记录的空壳
└── web/
    ├── index.html      # 页面（儿童友好：大按钮、拼音开关、只在点击时出声）
    └── vendor/         # 共享组件副本（themes / pinyin-pro / tts / voice / feedback）
```

**数据侧**（**仓库之外**，本技能目录里没有 `data/`）：`<data-root>/comp/data/`
（`config.json` 真实姓名/年级/班级、`notice.json` 真实通知含学校全名与老师邮箱、`state.json` 报名与打卡记录）。
路径一律走 `tools/data_paths.py` 的 `skill_dir("competition")` 解析，细节见同目录 `DATA.md`。

## 数据与接口（记录必须跨设备同步）

页面**不直读本机文件**，一切走门户服务器的接口，数据落 data-root 里本技能的 `data/`：

| 接口 | 说明 |
|---|---|
| `GET /api/competition` | 返回 `{ ok, childName, grade, className, notice, state }`；`notice` 来自 `data/notice.json`（含老师/邮箱，所以**只在服务器侧读**，不写进页面） |
| `POST /api/competition` | 提交 `{ enrollment, enrollmentUpdated, records }`，按 `ts` 合并落盘 `data/state.json` 并回传合并结果 |

- **记录格式**：`records["<项目id>:<步骤id>"]["YYYY-MM-DD"] = { v: 1|0, ts: 毫秒 }`；
  同一 项+天 按 `ts` 取新；**取消打卡也要写一条 `v: 0`**，否则取消动作同步不到别的设备；
  只接受格式合法的日期，脏 key 会被丢掉。
- **报名格式**：`enrollment = { "<类id>": "<项目id>" }`，跟着 `enrollmentUpdated`（毫秒时间戳）走，两台设备同时改也不打架。
- 页面打开时、切回前台时、每 15 秒各拉一次服务器状态；勾选后立刻推回，同步中再改会排队补推；
  `localStorage` 只当断网缓存，页面上有看得见的「☁️ 已同步 / ⚠️ 暂时连不上服务器」。
- **自检**：手机、平板、电脑打开同一页，看到的必须是同一份数据。

## 页面怎么用

- **我们参加哪一项**：按类选项目（每类最多一项）；选完「要求速查」只留你选的那几项。
- **要求速查**：展示要求 / 录制要求 / 上交要求 + 负责老师与邮箱，配「🔊 读一遍要求」。
- **备赛清单**：每个项目一组步骤，点一下＝打卡（✓），再点一下＝取消；顶部一行显示「正在给哪一天打卡」，
  切到过去某天就是补记。有「回到今天」。
- **打卡日历**：整页唯一的月视图；绿点＋数字＝那天完成几项，蓝框＝今天，橙框＝当前选中的那天；
  ◀ ▶ 换月、「回到今天」跳回本月；点某天，下面立刻列出那天完成的步骤与那天的录音。
- **练习心得**：录一段话，音频 + 文字一起留档（`web/vendor/voice.js`，不要自造录音 UI）。
- **拼音开关**：右上角「拼音」给项目名、步骤名加上拼音标注（本地 `pinyin-pro.js`）。
- **全部项目的要求 / 注意事项**：折叠区，随时翻原始要求。

3. 接线/撤销一律走脚本：`python tools/portal_wire.py add-page …` / `remove-page --id competition --unmount`。

## 首次使用（新用户）

1. 复制模板：`data-templates/*.json` → `data/`；
2. 把学校发的通知按 `data-templates/notice.json` 的结构整理进 `data/notice.json`
   （学校名、负责老师、邮箱照实填；项目/要求一段段摘录，**不要改写、不要编**）；
3. `data/config.json` 填孩子称呼、年级、班级；
4. 起门户：`python .trae/skills/growth-home/web/preview_server.py` → 打开 `http://localhost:8090/` → 「🏆 比赛」。

## 硬性约定（违反就算没做完）

1. **隐私隔离**：真实学校全名、老师姓名与邮箱、孩子姓名只允许出现在 `data/`；
   页面、脚本、`SKILL.md`、`data-templates/` 里一律不得出现（`data-templates/notice.json` 用占位符）。
2. **记录跨设备同步**：见上表；`localStorage` 只当断网缓存。
3. **语音双显示**：音频 + 识别文字一起给，用 `web/vendor/voice.js`。
4. **儿童友好**：零外部依赖、大按钮、拼音标注、只在点击时出声、庆祝提示可点掉。
5. **不编内容**：要求、老师、邮箱、截止时间都来自真实通知；通知里没写的，页面就不用写。
6. **新需求不改公共页面**：本技能自己的页面自己扩展，别去改兄弟技能的页面。
