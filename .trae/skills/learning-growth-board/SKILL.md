# 学习成长看板

以「当天回忆 + 费曼讲解」为方法论：每天把老师的学情报告和亲子自由对话归档为结构化数据，持续积累成一块儿童友好的可视化成长看板——所学内容时间线、习惯打卡日历、卡点追踪、成长统计与周报。

回顾方式为**自由对话**：家长和孩子自由聊当天学校的事，把对话内容（文字或语音转写）发给本技能提取归档，不生成问题卡。

## 目录结构

代码全部在技能文件夹内，便于打包发布；**真实数据在仓库之外**。以技能根目录为基准（即本 `SKILL.md` 所在目录）：

**代码侧**（公开、可分发）：

```
learning-growth-board/
├── SKILL.md                     # 本文件
├── skill.json                   # 声明 url=learn / 代码目录 / 数据目录
├── DATA.md                      # 数据落在哪里（仓库之外的 data-root）
├── data-templates/              # 发布用的通用示例数据（不含任何个人信息）
│   ├── config.json
│   └── days/2026-03-02.json
└── web/                         # 看板网页与本地预览服务器
    ├── dashboard.html           # 主页面（双模式：动态fetch / 内嵌数据）
    ├── parent.html              # 家长中心（需家长做的事 + 需监督孩子完成的作业）
    ├── preview_server.py        # 局域网预览服务器（端口 8091）
    └── vendor/
        └── pinyin-pro.js        # 本地拼音库（无需联网）
```

**数据侧**（**仓库之外**，本技能目录里没有 `data/`）：`<data-root>/learn/data/`
（`config.json` 孩子姓名/学校/年级/班级、`days/` 每日归档一天一个 `YYYY-MM-DD.json`、
`weekly/` 周报一周一个 `YYYY-Www.json`）。

**路径解析**：数据读写一律走 `tools/data_paths.py`（`skill_dir("learning-growth-board")`），
例如当日归档路径为 `<data-root>/learn/data/days/2026-09-02.json`，细节见同目录 `DATA.md`。

## 首次使用引导（重要）

每次被调用时，先检查 `data/config.json` 中 `childName` 是否仍为模板值（如"小明"）或为空。若是，先引导用户提供：

1. **孩子基本信息**：姓名、学校、年级、班级（写入 `config.json`）
2. **第一份材料**：请用户发送老师当天的学情报告，或直接粘贴今天和孩子的对话

信息收齐前不要生成看板。用户可能一次只提供部分信息，已提供的立即写入，不重复追问。

## 每日工作流程

一天的数据可能分两次到达：白天/傍晚老师发学情报告，晚上家长和孩子聊完天粘贴对话。两者都写入**同一个当日文件** `data/days/<今天日期>.json`，先到先建，后到合并。

### 1. 收到学情报告时（文字或截图）

1. 仔细阅读，提取：
   - **当日所学**（`learned`）：老师教了什么（含常规训练，如坐姿、排队）
   - **习惯打卡项**（`habits`）：要求回家练习/坚持的事项（如"练习坐姿5-10分钟"）
   - **作业/家长配合项**（`homework`）：明确的书面或操作任务
   - **老师总体评价**：写入 `teacherReport.summary`
2. 原文存入 `teacherReport.raw`（截图则存转写后的文字）。
3. 若当日文件已存在（比如对话先到了），**合并**而不是覆盖。
4. **教材图片**：报告明确提到教材内容（如"语文/数学学了第2、3页"）时，优先复用工作区已有的教材扫描 `textbooks/pages/{学科}/p{PDF页序号:03d}.jpg`（页码换算见 `textbooks/index.json` 的 `page_rule`：印刷页码 = PDF页序号 - offset；语文/数学 offset 为 5）。把**绝对 URL 路径**（如 `/textbooks/pages/语文/p007.jpg`）写入对应 `learned` 条目的 `images` 数组，由成长家园门户（8090）统一托管，看板上展示且可点击放大。若扫描库缺该学科/页，再请家长拍照存入 `data/images/`，路径写 `/learn/data/images/...`。图片未提供时如实留空，不要伪造教材图。

### 2. 收到亲子对话时（自由对话模式）

用户粘贴家长和孩子的聊天记录（可能含语音转写的识别误差）。提取时：

1. **当日所学**（`learned`）：孩子提到的课程内容、老师教的东西、同学互动中学到的规则。按学科归类（语文/数学/英语/劳动/体育/常规/其他）。
2. **亮点**（`review.highlights`）：孩子被表扬、主动发言、帮助他人等值得强化的时刻。
3. **卡点**（`review.stuckPoints`）：孩子讲不清楚、说不出来、混淆的地方——这是费曼方法的核心，务必捕捉。每个卡点记 `topic`（什么问题卡住）和 `note`（当时的表现）。
4. **情绪**（`review.mood`）：孩子当天整体情绪（开心/平静/疲惫/沮丧）。
5. **其他信息**（`notes`）：座位、放学时间、对老师的评价等背景信息。
6. 转写明显有误的地方（如"分作文"应为"分座位"），按上下文合理修正后归档，不必逐字保留。
7. 若孩子提到的内容与当天学情报告吻合，把该 `learned` 条目的 `sources` 合并为 `["teacherReport", "conversation"]`（双重印证，看板上会标⭐）。

归档完成后向用户简要复述：提取了几条所学、几个亮点、有没有卡点，并给一句具体的表扬建议（基于亮点）。

写入 `data/days/` 后**补一次配音**：调用 `voice-dubbing` 技能（`python .trae/skills/voice-dubbing/tools/gen_tts.py`），让当天「学到什么」的朗读句有音频，否则看板上的 🔊 在手机上可能没声音。

**能力清单参考**：`<data-root>/learn/capability-lists/语文-一年级能力清单.md` 与
`数学-一年级能力清单.md`（数据区里，不入库、不随包分发）列出一年级各能力板块（拼音/识字/加减法/图形等）及"每日回忆问题"。用途：
- 归档时观察孩子当天接触的内容落在哪个板块，便于周报按板块汇总；
- 家长问"聊什么"时，可挑清单里的回忆问题当聊天引子（口头用，不生成问题卡）；
- 原则仍是跟随学校进度、不超前，清单只用于回忆与观察。

### 3. 习惯打卡与卡点更新

用户随时可以说：
- "坐姿打卡了" → 找到当日（或指定日期）对应习惯项，置 `done: true`
- "XX卡点攻克了" → 找到对应 `stuckPoint`，置 `status: "cleared"`，可附 `clearedDate`
- "补讲了XX" → 若孩子仍卡，追加笔记；若通过，标记攻克

### 4. 生成周报（每周五或用户要求时）

读取本周（周一~当天）所有 `days/*.json`，生成 `data/weekly/<ISO周>.json`（结构见下），并向用户输出文字版周报：本周回顾天数、所学知识点汇总（按学科）、习惯打卡完成率、卡点攻克情况、亮点集锦、下周建议。

## 看板与两种交付模式

`web/dashboard.html` 为儿童友好风格：大字、拼音标注（本地 `vendor/pinyin-pro.js`）、语音朗读（Web Speech API）、打卡大按钮、庆祝动画。**零外部依赖**，所有资源本地化。

**模式 A — 局域网动态加载（本地电脑 + 手机同 WiFi）**
- 启动 `web/preview_server.py`（端口 **8091**，避免与书包清单的 8090 冲突），页面通过 `GET /api/data` 一次性获取 `{ config, days, weekly }`。
- 手机浏览器访问 `http://<电脑IP>:8091/web/dashboard.html`。
- 修改 `data/` 后刷新页面即生效。

**模式 B — 单文件内嵌数据（云端/无局域网环境）**
- 复制 `dashboard.html` 为新文件，把 `const EMBEDDED_DATA = null;` 替换为实际数据对象（形状与 `/api/data` 返回一致：`{ config, days, weekly }`）。
- 将 `vendor/pinyin-pro.js` 内容内联到 HTML 的 `<script>` 标签中，确保完全离线可用。
- 产出**自包含单文件 HTML** 交付。

## 家长中心（`web/parent.html`）

门户首页的「家长」标签打开它，家长在这看两块内容：**需要家长做的事** 和 **需要监督孩子完成的作业**。

- **需要家长做的事**：来自 `days[].parentTasks`（准备材料 / 查看签字 / 其他），勾选状态记在本机 `lgb_parent_done`，是家长自己的待办，与孩子无关。
- **需要监督孩子完成的作业**：**与孩子的打卡内容同步**——不读学习看板的习惯项，也不认本机的勾选状态，而是直接读孩子在各学科页打卡的同一份数据：
  - `GET /api/homework` 作业卡（科目、说明、附件、有效期）
  - `GET /api/homework/checkins` 打卡记录（服务器为准，逐项逐日；`v=0` 的取消记录算「没打卡」）
  - `GET /api/voice?scope=homework` 打卡时录的那句话（音频 + 文字双显示，点「▶️ 听」播放原始录音）
  - 页面打开时拉一次，之后每 12 秒 + 切回前台/重新聚焦时各拉一次，孩子在学科页打完卡这里就跟着变；每张卡显示「今天待打卡 / 已打卡 / 当时没打卡」，多天作业还带有效期、已打卡天数、连续天数与最近 7 天圆点，附件可点开打印。**家长页只读**，不会改动孩子的打卡记录。
  - 页面底部两个开关（互不影响）：**「显示已完成的」**（默认只看未完成的）和**「显示已过期的（N）」**。默认只列「今天还能打卡且还没打卡」的作业，已过期的历史作业收起来；过期的卡分「✅ 已完成 / ⏰ 当时没打卡」两种状态，`start > 今天` 的算「还没开始」不算过期，不会被这个开关收掉。列表被收空时会明确写出「已收起 N 项已过期的作业（其中 M 项当时没打卡）」，不会让人以为作业丢了。
- **看板里还没加入打卡的任务**：学习看板里没被做成作业卡的 `habits`（按名字去重，与作业卡同名的不重复列）收在页面底部折叠区，提醒家长让孩子在对应学科页点「＋加入」，这部分的完成情况**不混进**上面的待办计数。
- 单文件/离线打开（拿不到门户接口）时自动退化成「家长事项 + 看板任务」，顶部提示暂时连不上服务器，不报错。

## 数据结构

### config.json
```json
{
  "childName": "孩子的名字",
  "school": "学校名称",
  "grade": "年级",
  "className": "班级",
  "semester": "学期"
}
```

### days/YYYY-MM-DD.json
```json
{
  "date": "2026-09-02",
  "weekday": "周三",
  "schoolDayIndex": 2,
  "teacherReport": {
    "received": true,
    "raw": "老师反馈原文",
    "summary": "一句话总结"
  },
  "conversation": {
    "received": true,
    "summary": "亲子对话要点摘要"
  },
  "learned": [
    {
      "id": "2026-09-02-1",
      "subject": "常规",
      "content": "学习坐姿、站姿、排队和上课规范",
      "sources": ["teacherReport", "conversation"]
    }
  ],
  "habits": [
    {
      "id": "2026-09-02-sit-posture",
      "name": "正确坐姿练习",
      "detail": "回家练习5-10分钟",
      "done": false
    }
  ],
  "homework": [],
  "parentTasks": [
    { "id": "2026-09-22-p1", "type": "check", "text": "数学大册第3页，查看并签字", "done": false }
  ],
  "review": {
    "done": true,
    "highlights": ["值得表扬的具体时刻"],
    "mood": "开心",
    "stuckPoints": [
      { "id": "sp-2026-09-02-1", "topic": "卡住的问题", "note": "当时的表现", "status": "pending", "clearedDate": null }
    ]
  },
  "notes": "座位、放学时间等背景信息"
}
```

字段约定：
- `schoolDayIndex`：入学第几天（可空）。
- `learned[].subject` 取值：语文 / 数学 / 英语 / 劳动 / 体育 / 美术 / 音乐 / 常规 / 其他。
- `sources` 取值：`teacherReport`、`conversation`、`parent`（家长直接转述）。
- `learned[].images`（可选）：图片的**绝对 URL 路径**数组，如 `/textbooks/pages/语文/p007.jpg`（门户托管的教材扫描）或 `/learn/data/images/xxx.jpg`（家长拍照补录）；无图时省略或留空数组。模式 B（单文件内嵌）需把图片转成 base64 data URI 才能离线显示。
- `parentTasks[].type` 取值：`material`（准备材料）/ `check`（查看签字）/ `other`（其他）；`id` 建议 `日期-p序号`。这一块只给**家长**看（家长中心的「需要家长做的事」），不进孩子的看板统计。
- 缺材料的块保持 `received: false` / 空数组，不要编造内容。

### weekly/YYYY-Www.json
```json
{
  "week": "2026-W36",
  "dateRange": "2026-09-01 ~ 2026-09-05",
  "reviewDays": 2,
  "totalLearned": 8,
  "subjectDistribution": { "常规": 4, "英语": 1, "劳动": 1 },
  "habitsDone": 1,
  "habitsTotal": 1,
  "stuckCleared": 0,
  "stuckPending": 1,
  "highlights": ["本周亮点集锦"],
  "nextWeekFocus": ["下周建议关注"]
}
```

## 打包发布

本技能可独立发布给其他家长：

1. **清空真实数据**：删除 `data/days/`、`data/weekly/` 下所有文件，把 `data/config.json` 替换为 `data-templates/config.json` 的内容，再放入一份示例日归档（`data-templates/days/` 中的虚构数据）。
2. **打包**：将整个 `learning-growth-board/` 文件夹压缩为 zip，或放入目标项目的 `.trae/skills/` 目录。
3. **新用户首次使用**：技能检测到模板值后，按"首次使用引导"逐步收集信息。

## 注意事项

- 隐私：归档内容仅限家庭使用；对外分享看板截图时，避免暴露学校全名、班级和其他孩子的姓名（与本项目安全规则一致）。
- 只归档事实和孩子真实说出的内容；不替孩子编造"所学"。材料缺失时如实留空。
- 卡点是宝贵信号，语气上永远是"我们发现一个小怪兽"，不是"你没学会"。
- 拼音与语音功能遵循已验证的工程约定：本地 pinyin-pro 库、朗读统一播放 `voice-dubbing` 技能预生成的 edge-tts 音频（浏览器朗读仅作兜底）、只在用户点击时出声。
- 学情报告若跨越多天或补发前几天的内容，拆分到对应日期的文件中。
