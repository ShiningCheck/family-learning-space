# 孩子画作档案

为孩子的画作建立持续累积的档案系统：每次收到画作+孩子描述即归档一条记录，提取卡通形象进入形象档案；按需输出统计；每累积 10 幅提醒整理，整理时生成画册、故事册、绘本三种 HTML 成品。全部内容与成长家园门户（growth-home）的「画作」标签页打通，网站自动展示最新档案。

## 档案结构（代码在本技能目录，数据在仓库外；门户以 /art/* 托管）

**代码侧**（本技能目录，公开、可分发）：

```
xiaoshan-art-archive/
├── SKILL.md
├── skill.json           # 声明 url=art / 代码目录 / 数据目录
├── DATA.md              # 数据落在哪里（仓库之外的 data-root）
├── web/
│   ├── art.html         # 画作页：画廊+详情+形象统计+画册书架（门户“画作”标签页）
│   └── vendor/          # pinyin-pro.js + themes.js + tts.js + voice.js + feedback.js（与门户同款，主题自动同步）
└── data-templates/      # 匿名初始数据（data-root 里的 data/ 由它生成）
```

**数据侧**（**仓库之外**，本技能目录里没有 `data/`、`images/`、`audio/`、`output/`）：`<data-root>/art/`
（`data/config.json` childName / archiveTitle、`data/index.json` 总索引每幅画一条记录、
`data/characters.json` 卡通形象档案、`data/outputs.json` 已生成的整理成品清单、
`images/` 画作图片副本命名 `001_原文件名.jpg`、`audio/` 早期归档的原始录音、
`output/` 生成的 HTML 画册/故事册/绘本）。路径一律走 `tools/data_paths.py` 的
`skill_dir("xiaoshan-art-archive")` 解析，细节见同目录 `DATA.md`。

重要：用户发来的图片/录音必须**复制**进 `<data-root>/art/images/`、`<data-root>/art/audio/`，
不得只引用临时附件路径（附件可能被清理）。

画作页「记一幅画」弹层里的录音已经改用全站通用的语音组件（`web/vendor/voice.js`）：孩子说完**自动识别成文字填进描述框**，音频与文字一起存到门户服务器的 `<data-root>/web/data/voice/`（场景名 `art-describe`），保存画作时只把语音地址挂到画作记录上（`audio` 字段存 `/data/voice/...` 绝对路径，`voiceId` 记来源），因此同一段语音不会存两遍。手机上用自带「录音机」录好再点「📁 上传录音」即可（非 https 下浏览器拿不到麦克风）。

门户通用约定：**语音输入必须双显示**——音频能点开听、文字能看见读（画作页是「▶️ 播 + 描述文字」成对出现），不许只留音频或只留文字；详见 `growth-home/SKILL.md` 的「通用约定」一节。

## 流程一：记录一幅画

触发：用户发送画作图片并附孩子描述（文字或录音），或说“记一幅画”。

1. **读取图片**：用读图能力查看画面内容。
2. **存图**：复制到 `images/`，编号为当前最大编号+1（三位数，如 `001`）。**方向校正**：照片拍摄方向可能与画作实际方向不一致，必须先看图判断正确朝向（草地/地面在下、形象脸部 upright、花朵朝上生长等重力线索），需要旋转时生成旋转副本比对确认后再存档。Windows 可用 System.Drawing：`Rotate90FlipNone`=顺时针90°、`Rotate270FlipNone`=逆时针90°。拿不准时问用户。
3. **处理描述**：
   - 文字描述：原文记录。
   - 录音（画作页录的）：页面已自动识别成文字填进描述框，音频存在门户 `data/voice/art-describe/` 下并在画作记录里留了地址（`audio` + `voiceId`），核对该地址能播即可。
   - 录音（用户直接把音频发到对话里）：复制到 `audio/`，并转录为文字（优先调用门户服务器已有的识别接口/`growth-home/web/asr.py` 的 `transcribe()`；环境不可用或转录失败时，请用户粘贴描述文字）。转录文本与原文一并存档。
4. **生成标记**：
   - 编号：No.00X 自动递增。
   - 标题：由 AI 根据画面+孩子描述命名，如《三只小鸟和大树》。
   - 日期：记录当天。
   - 标签：形象标签 + 主题标签（花/鸟/树/昆虫等）。
5. **提取卡通形象**（三步）：
   - 看图识别：识别形象实体（物种+颜色+特征，如“粉色长尾鸟”）与场景元素。
   - 结合描述：从孩子描述/转录文本中提取角色与命名（如“这是小鸟妈妈”），与看图结果合并。
   - 档案匹配：与 `data/characters.json` 比对。特征吻合则归入已有形象（appearances 追加本画编号）；新形象建新条目。匹配不确定时，用一句话向用户确认（如“这只蓝色小鸟和上次的‘小蓝’是同一只吗？”），不要擅自合并或新建。
6. **写入 `data/index.json`**（追加记录），并向用户简短回执：编号+标题+形象列表+当前累计幅数。
7. **数量提醒**：若累计幅数为 10 的倍数，主动提示“已累积 10 幅新画，要不要整理成画册/故事册/绘本？”
8. **补配音**：新增画作后调用 `voice-dubbing` 技能（`python .trae/skills/voice-dubbing/tools/gen_tts.py`），补上「标题＋孩子口述」的朗读音频，否则画作页点 🔊 在手机上可能没声音。

### index.json 记录格式

```json
{
  "id": "001",
  "date": "2026-09-04",
  "title": "三只小鸟和大树",
  "image": "images/001_xxx.jpg",
  "audio": "audio/001_xxx.m4a",
  "voiceId": null,
  "description": "孩子原话或转录文本",
  "characters": ["粉色小鸟", "蓝色小鸟"],
  "tags": ["鸟", "花", "树"]
}
```

`audio` 无录音时为 `null`。`image`/`audio` 均为相对本技能根目录的路径；由画作页录音产生的记录里 `audio` 是 `/data/voice/...` 绝对路径（门户托管），`voiceId` 是对应的语音记录 id。

### characters.json 格式

```json
{
  "粉色小鸟": {
    "visual": "粉色、长尾、翅膀有条纹",
    "aliases": ["小鸟妈妈"],
    "first_seen": "2026-09-04",
    "appearances": ["001"]
  }
}
```

## 流程二：查看统计

触发：用户说“看统计”“形象统计”等。

- 统计内容固定两项：**形象出现排行**（按 appearances 数量降序）与**月度趋势**（每月画作数、当月新出现形象）。
- 默认在对话中用表格简要回复；用户要文件时生成 HTML 统计页存入 `output/`。
- 网站画作页已内置同样的统计展示，可引导用户到门户「画作」页查看。

## 流程三：整理画册 / 故事册 / 绘本

触发：用户说“整理画册/故事册/绘本”，或接受 10 幅提醒。

- **范围**：默认全部档案；用户可指定某月或某形象。
- **产出**：默认一次生成三种 HTML，放入 `output/`；用户指定单一形态时只生成该种。
  - **画册**：按形象/主题分类的画作合集，以展示画作为主，附形象统计页（排行+月度趋势）。
  - **故事册**：按时间线把孩子的描述串成成长故事，配对应画作插图。
  - **绘本**：封面（含孩子昵称与日期范围）+ 一页一画，孩子原话作配文，翻页版式。
- **设计**：生成 HTML 前必须调用 frontend-design skill 做设计；风格温暖童趣，中文字体使用 `Noto Sans CJK SC`；图片以相对路径引用（成品位于 `output/`，引用图片用 `../images/xxx.jpg`），保证在门户 `/art/` 托管下可正常打开。
- **登记成品**：每生成一个成品，向 `data/outputs.json` 追加一条：
  ```json
  { "type": "绘本", "title": "孩子绘本·第1册", "date": "2026-09-04", "file": "output/huiben-1.html" }
  ```
  画作页的「画册书架」会自动展示这些成品链接。
- 完成后向用户提供每个成品的可打开链接与一句话简介。

## 流程四：网站展示（成长家园门户集成）

- 门户 `growth-home/web/preview_server.py` 已把 `/art/*` 映射到本技能根目录；首页 CORE_TABS 含「画作」标签页（🎨），iframe 加载 `/art/web/art.html`。
- 记录画作、更新统计、登记成品后**无需额外发布**：数据都在 `data/`，刷新门户「画作」页即见最新内容。
- 启动方式：`python <growth-home技能目录>/web/preview_server.py`，浏览器访问 `http://localhost:8090/` 切到「画作」标签；也可直接访问 `/art/web/art.html`。
- 画作页零外部依赖，遵循门户工程约定：themes.js 主题与门户实时同步、pinyin-pro 拼音标注、语音朗读（iOS cancel 后留 50ms 再 speak）。
- 若修改了门户映射或标签页，同步更新 `growth-home/SKILL.md` 的路径映射表。

## 注意事项

- 全程使用中文回复用户。
- 回执与成品语气亲切、鼓励，面向家长阅读。
- 不擅自删除或覆盖档案记录；编号只增不减。
- 若用户一次发送多幅画，逐幅执行流程一并分别回执。
